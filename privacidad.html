Política de privacidad de Lucía correo

Última actualización: 26 de octubre de 2026.

Quién la usa

Lucía correo es una herramienta interna de JFAutomatic, de uso exclusivo de su propietario y sobre sus propias cuentas de correo. No ofrece ningún servicio a terceros.

Qué datos trata

Con el permiso que el propietario concede a través de Google (y de Microsoft), la herramienta accede a los mensajes y etiquetas de sus buzones para leerlos, resumirlos, organizarlos (archivar, etiquetar, marcar como leído) y preparar borradores. El envío de cualquier correo y el paso de un mensaje a la papelera requieren siempre su aprobación expresa.

Dónde se guardan

Las credenciales de acceso se guardan cifradas en el equipo del propietario. El contenido de los correos solo se procesa para atender sus peticiones y no se guarda de forma permanente fuera de su buzón.

Con quién se comparten

Los datos no se venden ni se ceden a terceros. Para generar resúmenes y borradores, el texto necesario se procesa con un proveedor de modelos de lenguaje que actúa como encargado del tratamiento. No se usan para publicidad ni para entrenar modelos.

Uso de los datos de Google

El uso y la transferencia de la información recibida de las API de Google se ajustan a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo retirar el acceso

El acceso puede retirarse en cualquier momento desde myaccount.google.com/permissions (Google) o account.live.com/consent/Manage (Microsoft).
